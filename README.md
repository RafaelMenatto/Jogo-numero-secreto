# 🎯 Jogo do Número Secreto

Um jogo web interativo desenvolvido em JavaScript onde o jogador deve adivinhar um número secreto sorteado aleatoriamente pela aplicação. O projeto foi construído para praticar e consolidar conceitos fundamentais de lógica de programação, manipulação do DOM e boas práticas de desenvolvimento web.

---

## 🚀 Funcionalidades

- **Gerador Aleatório Inteligente:** Sorteia números dentro de um intervalo pré-definido, evitando repetições imediatas.
- **Feedback em Tempo Real:** Informa se o número secreto é maior ou menor que o palpite inserido.
- **Contador de Tentativas:** Acompanha e exibe o número total de palpites necessários até a vitória.
- **Recurso de Voz:** Narração áudio-assistida das instruções e feedbacks usando sintaxe de voz.
- **Reinício Rápido:** Botão para iniciar uma nova partida mantendo o estado do jogo limpo e fluido.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização responsiva e moderna da interface.
- **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM e controle de estado.
- **ResponsiveVoice.js:** Biblioteca para síntese de voz (áudio do jogo).
